# deerflow.config.projects_config-档案

## 一、这个模块是干什么的

这个模块管理用户项目功能的配置。

项目是用户的文档货架。

功能包括指令注入、货架索引、回收站。

这个配置限制指令的大小。

限制货架索引的规模。

决定回收站文档保留多少天。

## 二、模块里的主要成员

### 1、ProjectsConfig类

`instructions_max_bytes`是项目指令的UTF-8字节上限，默认8192。

写入时强制，超了网关返回422。

网关从不截断。

多字节字符按UTF-8字节长度计，不按字符数。

`shelf_index_max_entries`是每次运行渲染进`<documents>`索引的最大货架条目数，默认50。

`shelf_index_max_bytes`是渲染索引的UTF-8字节上限，默认4096。

中文名时字节上限通常先于条目上限起约束作用。

`trash_retention_days`是回收站文档保留天数，默认30天。

到期后回收清理可以清除。

### 2、非法值降级

`_drop_invalid_values`校验器把非法值降级为默认值。

配置文件里的坏值不能让配置加载崩溃。

降级时打警告。

直接构造时Field约束仍然强制生效。

只接受整数兼容的值。

布尔不行。

无限浮点、nan、小数浮点都降级。

强制转换后的int才留下来。

## 三、它和谁协作

`app_config.py`的`projects`字段是这份配置。

项目路由和货架渲染消费这份配置。

`paths.py`提供项目目录的结构。

## 四、重要性评级

评级：5分。

理由：项目是产品特性，配置面是三个限额加一个保留期。非法值降级的实现很细致（布尔、inf、nan都有处理）。但整体是支撑性配置。

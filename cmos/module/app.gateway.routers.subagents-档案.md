# app.gateway.routers.subagents-档案

源码路径是backend/app/gateway/routers/subagents.py。

## 一、这个模块是干什么的

subagents.py是子智能体定义的目录和管理CRUD API。

子智能体是主智能体委托出去的执行单元。

子智能体定义包含名称、提示词、工具配置。

这个模块列目录和管理这些定义。

这个模块有230行。

## 二、模块里的主要成员

路由前缀是/api/subagents。

### 1、端点列表

- GET ""列出子智能体目录。
- POST ""创建托管子智能体。
- PUT "/{name}"更新托管子智能体。
- DELETE "/{name}"删除托管子智能体。

### 2、目录语义

GET是目录端点。

目录对认证用户开放。

管理端点是管理员操作。

创建和更新做定义校验。

校验失败的请求返回400。

ValidationError被映射成错误详情。

## 三、它和谁协作

上游是前端的子智能体管理页。

下游是子智能体定义存储。

主智能体运行时读取子智能体定义。

委托工具按定义创建子智能体。

## 重要性评级

评级是5分。

理由如下。

子智能体是DeerFlow的重要架构。

委托执行是主智能体的核心能力。

管理CRUD让子智能体定义可维护。

但目录读取是低频操作。

普通用户不直接操作子智能体定义。

委托逻辑本身在harness层。

所以评级是5分。

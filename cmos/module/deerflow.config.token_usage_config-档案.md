# deerflow.config.token_usage_config-档案

## 一、这个模块是干什么的

这个模块管理令牌用量追踪的配置。

令牌用量追踪记录每次调用的令牌消耗。

这是成本可见性的基础。

追踪通过中间件实现。

这个模块只有开关配置。

## 二、模块里的主要成员

### 1、TokenUsageConfig类

只有一个字段。

`enabled`决定是否启用令牌用量追踪中间件，默认开启。

## 三、它和谁协作

`app_config.py`的`token_usage`字段是这份配置。

令牌用量中间件消费这个开关。

`token_budget_config.py`处理预算强制，这个模块只管追踪记录。

## 四、重要性评级

评级：3分。

理由：这个模块只有一个布尔开关。追踪的实际逻辑都在中间件里。是整个config包里最小的模块之一。

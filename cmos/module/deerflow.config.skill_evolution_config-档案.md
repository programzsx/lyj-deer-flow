# deerflow.config.skill_evolution_config-档案

## 一、这个模块是干什么的

这个模块管理代理自管技能演化的配置。

技能演化指代理自己创建和修改技能。

代理可以把学到的经验沉淀成新技能。

写在技能的自定义目录下。

这个功能默认关闭。

原因是让代理自己写技能有安全风险。

需要配套的安全仲裁。

## 二、模块里的主要成员

### 1、SkillEvolutionConfig类

`enabled`是开关，默认关闭。

开启后代理可以在技能的自定义目录下创建和修改技能。

`moderation_model_name`是技能安全仲裁用的模型。

不设置时用主对话模型。

`security_fail_closed`决定仲裁模型不可用时怎么办。

True时阻断技能写入。

这是fail-closed，安全优先。

False时允许非可执行内容写入并给警告。

可执行内容仍然阻断。

## 三、它和谁协作

`app_config.py`的`skill_evolution`字段是这份配置。

技能演化运行时消费这份配置。

技能安全扫描与这里的仲裁配合。

## 四、重要性评级

评级：5分。

理由：技能演化是高级能力，默认关闭。fail-closed的设计是安全关键点。但配置面小，只有三个字段。

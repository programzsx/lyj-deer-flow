# deerflow.config.suggestions_config-档案

## 一、这个模块是干什么的

这个模块管理自动跟进建议的配置。

AI回答结束后可以生成跟进问题建议。

帮用户决定下一步问什么。

这个配置控制这个功能开不开、最多生成几条。

## 二、模块里的主要成员

### 1、SuggestionsConfig类

两个字段。

`enabled`决定是否在AI回答末尾生成跟进问题建议，默认开启。

`max_suggestions`是最大建议条数，默认3，上限5。

两个常量定义默认值和上限。

## 三、它和谁协作

`app_config.py`的`suggestions`字段是这份配置。

跟进建议的路由消费这个配置。

## 四、重要性评级

评级：3分。

理由：跟进建议是纯体验层的小功能。只有两个字段。是典型的薄配置模块。

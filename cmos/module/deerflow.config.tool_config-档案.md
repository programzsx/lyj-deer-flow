# deerflow.config.tool_config-档案

## 一、这个模块是干什么的

这个模块定义工具和工具组的配置结构。

DeerFlow在`config.yaml`里声明可用的工具。

每个工具属于一个工具组。

工具通过`use`字段指向提供者的类路径。

这个模块就是这两个配置节的结构定义。

## 二、模块里的主要成员

### 1、ToolConfig类

这个类是一个工具的配置。

`name`是工具的唯一名。

`group`是所属工具组的名字。

`use`是工具提供者的变量名。

比如`deerflow.sandbox.tools:bash_tool`。

两个类都允许额外字段。

原因是不同提供者可能需要不同的额外参数。

### 2、ToolGroupConfig类

这个类是一个工具组的配置。

只有`name`一个必填字段。

额外字段同样允许。

## 三、它和谁协作

`app_config.py`的`tools`和`tool_groups`字段是这两个类的列表。

工具工厂按`use`导入实际实现。

社区工具调用时按名字查这两个配置。

## 四、重要性评级

评级：5分。

理由：工具声明是系统接工具的基础结构。但模块本身只有两个薄模型，几乎没有逻辑。额外字段透传是它的主要设计点。

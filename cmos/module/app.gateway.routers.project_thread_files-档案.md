# app.gateway.routers.project_thread_files-档案

源码路径是backend/app/gateway/routers/project_thread_files.py。

## 一、这个模块是干什么的

project_thread_files.py是项目成员线程的会话文件视图。

项目里有多个线程。

每个线程有自己的上传文件和产物文件。

这个模块把成员线程的文件聚合起来。

这是一个只读聚合视图。

这个模块只有160行。

## 二、模块里的主要成员

路由前缀是/api/projects/{project_id}/thread-files。

### 1、端点列表

- GET ""分页返回成员线程的文件。

### 2、聚合逻辑

_list_thread_files读一个线程的文件。

上传文件走list_files_in_dir。

产物文件走sandbox_outputs_dir目录列举。

产物文件没有其他列举入口。

这个聚合是唯一的产物列举来源。

_entry构建文件条目。

条目带类型，类型是upload或output。

### 3、无自有存储

这个模块不保存任何数据。

线程文件消失，聚合结果就消失。

线程的排序和项目线程列表一致。

归档线程不出现。

## 三、它和谁协作

上游是前端项目的文件面板。

下游是线程上传目录和产物输出目录。

授权复用项目成员检查。

## 重要性评级

评级是4分。

理由如下。

这个模块是一个纯只读聚合视图。

它不保存数据，不修改状态。

价值是给项目一个统一的文件视角。

没有它，用户要进每个线程看文件。

但它是辅助视图，不是核心路径。

体量小，逻辑简单。

所以评级是4分。

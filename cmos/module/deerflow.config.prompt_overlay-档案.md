# deerflow.config.prompt_overlay-档案

## 一、这个模块是干什么的

这个模块定义提示覆盖。

提示覆盖是运维人员拥有的字面文字。

运维可以在组装好的系统提示前面或后面附加一段固定文字。

这些文字字面生效，不做任何加工。

这个模块定义这个覆盖的结构和应用方法。

## 二、模块里的主要成员

### 1、PromptOverlay类

只有两个字段。

`prepend`是加在提示前面的文字，默认空。

`append`是加在提示后面的文字，默认空。

两个字段都是strict模式。

意思是必须是真字符串，不做隐式转换。

`model_config`禁止额外字段。

### 2、apply()

应用覆盖。

把前置文字、原提示、后置文字用两个空行连接。

空的部分跳过。

所以默认配置下原提示保持原样。

## 三、它和谁协作

`app_config.py`的`lead_prompt_overlay`字段是这份配置。

`subagents_config.py`的`SubagentOverrideConfig`也有这个覆盖。

主代理和子代理的系统提示组装点调用`apply()`。

子代理的批量服务也消费它。

## 四、重要性评级

评级：4分。

理由：提示覆盖是运维控制系统提示的直接手段。结构极小，只有一个apply方法。strict模式和extra=forbid是它的主要设计点。

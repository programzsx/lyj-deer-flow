# deerflow.config.skill_scan_config-档案

## 一、这个模块是干什么的

这个模块管理技能安全扫描的配置。

技能是可执行的代码包。

恶意技能可能带来安全风险。

系统对技能做安全扫描。

扫描分两层。

第一层是确定性的分析器。

第二层是LLM扫描器。

这个配置控制第一层是否运行。

## 二、模块里的主要成员

### 1、SkillScanConfig类

只有一个字段。

`enabled`决定确定性的SkillScan分析器是否在LLM扫描器之前运行，默认开启。

## 三、它和谁协作

`app_config.py`的`skill_scan`字段是这份配置。

技能扫描运行时消费这个开关。

`skill_evolution_config.py`处理技能写入的安全仲裁。

## 四、重要性评级

评级：4分。

理由：单开关模块。确定性扫描是安全链路的第一道，默认开启是对的。但配置面实在太小。

# deerflow.config.input_polish_config-档案

## 一、这个模块是干什么的

这个模块管理发送前输入润色的配置。

用户在输入框写完草稿后。

发送之前可以让AI润色这段文字。

这个配置控制润色功能开不开、草稿最多多长。

## 二、模块里的主要成员

### 1、InputPolishConfig类

三个字段。

`enabled`决定是否启用发送前输入润色，默认开启。

`max_chars`是润色端点接受的草稿最大字符数，默认4000。

`model_name`是可选的模型覆盖。

不设置时用默认模型。

## 三、它和谁协作

`app_config.py`的`input_polish`字段是这份配置。

输入润色端点消费这份配置。

## 四、重要性评级

评级：3分。

理由：输入润色是编辑器体验层的小功能。只有三个字段。典型的薄配置模块。

# InputPolishConfig档案

一、这个类是干什么的

InputPolishConfig是输入润色功能的配置类。输入润色发生在消息发送之前。这个类控制这个功能要不要开。这个类还控制润色入口能接受多大的草稿。这个类继承自pydantic的BaseModel。

二、类的成员

（一）字段

- enabled：布尔值。默认值是True。这个字段表示是否启用输入润色。
- max_chars：整数。默认值是4000。最小值是1。这个字段限制润色入口接受的最大草稿字符数。
- model_name：字符串或None。默认值是None。这个字段允许为润色单独指定模型。不指定就用默认模型。

（二）方法

这个类没有自定义方法。校验工作由Field的约束完成。

三、它和谁协作

AppConfig持有这个类。AppConfig的input_polish字段是这个类的实例。润色相关的执行代码读取这个实例来决定行为。

四、重要性评级

评级：4分。

理由：输入润色是体验增强功能。关闭这个功能不影响主流程。这个类只有三个简单字段。所以重要性偏低。

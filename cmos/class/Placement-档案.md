# Placement档案

一、这个类是干什么的

Placement是扩展中间件位置的枚举类。这个类继承自StrEnum。位置声明成语义保证。不是结构位置。声明者说需要观察原始工具返回。不说把我放到第三层。声明按轴和端消除歧义。宿主保持重构中间件栈的自由。

二、类的成员

（一）枚举值

- MODEL_LOGICAL：值为model_logical。模型轴的外端。保证在重试和错误处理之外。每次逻辑决策触发一次。不管宿主重试多少次。
- MODEL_PHYSICAL：值为model_physical。模型轴的内端。保证在所有请求变换中间件之内。每次物理提供者调用触发一次。重试会重新进入。
- TOOL_VISIBLE：值为tool_visible。工具轴的外端。保证在截断、清洗和错误包装之外。观察模型最终看到的内容。
- TOOL_RAW：值为tool_raw。工具轴的内端。保证紧邻真实可调用边界。观察工具的原始返回。
- STANDARD：值为standard。没有前后处理要求。和其他STANDARD贡献者的相对顺序不保证。

（二）方法

StrEnum提供的能力。没有自定义方法。

三、它和谁协作

MiddlewarePlacement的placement字段是这个枚举类型。扩展贡献中间件时声明位置。宿主按声明把中间件插入栈。

四、重要性评级

评级：6分。

理由：这个枚举是中间件位置语义的核心。语义声明代替结构位置。保证扩展观察到正确的内容。所以重要性中等偏上。

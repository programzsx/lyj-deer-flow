# QRLoginError档案

## 一、这个类是干什么的

QRLoginError是微信二维码登录的异常。

它是一个Exception子类。

登录流程出错时抛它。

比如会话找不到。

比如另一个管理员正在连接。

比如二维码请求失败。

比如微信返回了无效的二维码。

它携带两样东西。

错误描述。

HTTP状态码。

HTTP路由用它把异常转成合适的HTTP响应。

## 二、类的成员

### （一）字段

1、status_code

HTTP状态码。

路由用它决定返回给浏览器的状态码。

### （二）方法

1、__init__(detail, status_code)

构造异常。

detail是错误描述文本。

status_code默认400。

## 三、它和谁协作

QRLoginError是微信二维码登录的信号异常。

它由WechatQRLogin抛出。会话找不到抛404。管理员冲突抛409。二维码请求失败抛502。凭据应用失败抛502。

它被Gateway的HTTP路由捕获。路由读它的status_code构造HTTP响应。

它的错误描述文本发给浏览器展示给管理员。

它只在微信二维码登录流程里使用。

## 四、重要性评级

评级：3分。

理由如下。

它是登录流程错误到HTTP响应的桥梁。

没有它，登录错误无法携带正确的HTTP状态码。

它只是个简单的信号异常，只有一个字段。触发场景限于微信扫码登录。所以只有3分。

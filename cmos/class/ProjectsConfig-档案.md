# ProjectsConfig档案

一、这个类是干什么的

ProjectsConfig是用户项目功能的配置类。对应Phase 2。功能包括指令注入、书架和回收站。这个类控制项目指令的字节上限。这个类还控制书架索引边界和回收站保留期。这个类继承自pydantic的BaseModel。

二、类的成员

（一）字段

- instructions_max_bytes：整数。默认值是8192。取值范围是256到262144。这个字段是项目指令的硬UTF-8字节上限。写入时强制。网关用422拒绝超大的值。从不截断。
- shelf_index_max_entries：整数。默认值是50。取值范围是1到500。这个字段是每次运行渲染进documents索引的书架条目上限。
- shelf_index_max_bytes：整数。默认值是4096。取值范围是512到65536。这个字段是渲染的documents索引的UTF-8字节上限。中文名通常先触发这个上限。
- trash_retention_days：整数。默认值是30。取值范围是1到3650。这个字段是回收站文档保持可恢复的天数。到期后保留清理可以清掉。

（二）方法

- _drop_invalid_values：模型校验器。这个方法对无效值回退到字段默认值并打警告。格式错误或越界的值不能崩掉配置加载。键被丢弃。默认值生效。只接受整数兼容的值。分数浮点数、inf、nan和非数字都回退。转换后的整数留下。Pydantic看不到原始值。

三、它和谁协作

AppConfig持有这个类。AppConfig的projects字段是这个类的实例。项目文档的书架渲染代码读取索引上限。回收站清理代码读取trash_retention_days。

四、重要性评级

评级：5分。

理由：项目功能是用户资产管理。字节上限保护上下文不被撑爆。容错校验防止坏配置崩掉加载。所以重要性中等。

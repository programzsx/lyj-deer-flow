# TaskContinuityConfig档案

一、这个类是干什么的

TaskContinuityConfig是任务连续性功能的配置类。这个功能提供线程本地的working notes。这个功能还提供压缩后的来源回忆。这个功能默认关闭。用户可以选择开启。这个类继承自pydantic的BaseModel。

二、类的成员

（一）字段

- enabled：布尔值。默认值是False。这个字段表示功能是否开启。
- max_batches：整数。默认值是32。取值范围是1到64。这个字段限制批次数量的上限。
- max_records_per_batch：整数。默认值是256。取值范围是1到1024。这个字段限制每批记录数的上限。
- max_record_chars：整数。默认值是16000。取值范围是1000到64000。这个字段限制单条记录的字符数上限。

（二）方法

这个类没有自定义方法。所有约束都写在Field里。

三、它和谁协作

AppConfig持有这个类。AppConfig的task_continuity字段是这个类的实例。任务连续性的实现代码读取这些上限来控制内存占用。

四、重要性评级

评级：4分。

理由：这个功能默认关闭。开启与否不影响其他功能。这个类只描述容量上限。所以重要性偏低。

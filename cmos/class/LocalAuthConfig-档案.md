# LocalAuthConfig档案

一、这个类是干什么的

LocalAuthConfig是内置邮箱密码认证的配置类。这个类控制本地注册要不要允许。这个类还控制登录失败锁定策略。这个类继承自pydantic的BaseModel。

二、类的成员

（一）字段

- allow_registration：布尔值。默认值是True。这个字段表示是否允许访客自注册本地账户。账户只通过SSO提供时设为False。OIDC的配置策略不适用于本地注册。
- max_login_attempts：整数。默认值是5。最小值是2。这个字段是单个客户端IP允许的失败登录次数。达到次数就锁定本地登录。最小值2是刻意的。一次失败绝不能锁定IP。否则一次输入错误就会挡住共享出口IP后面的所有人。计数器是每个网关worker进程内的。多worker部署的有效尝试次数随worker数放大。
- lockout_seconds：浮点数。默认值是300.0。大于0。这个字段是IP达到失败次数后的锁定时长秒数。默认保留历史上的5分钟策略。

（二）方法

这个类没有自定义方法。这个类是纯数据类。

三、它和谁协作

AuthAppConfig持有这个类。AuthAppConfig的local字段是这个类的实例。本地登录路由读取这个实例。OIDCAuthConfig的SSO策略和本地注册是互斥的部署选择。

四、重要性评级

评级：6分。

理由：本地认证的暴力破解防护靠这个类。锁定策略太松会暴露暴力破解风险。太紧会挡住真实用户。所以重要性中等偏上。

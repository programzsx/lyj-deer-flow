# SkillScanConfig档案

一、这个类是干什么的

SkillScanConfig是技能安全扫描的配置类。这个类控制原生的确定性扫描器要不要跑。确定性扫描器在LLM技能扫描器之前运行。这个类继承自pydantic的BaseModel。

二、类的成员

（一）字段

- enabled：布尔值。默认值是True。这个字段表示是否在LLM技能扫描器之前运行原生的确定性SkillScan分析器。

（二）方法

这个类没有自定义方法。这个类只有一个开关字段。

三、它和谁协作

AppConfig持有这个类。AppConfig的skill_scan字段是这个类的实例。技能扫描流程读取这个开关来决定扫描顺序。

四、重要性评级

评级：5分。

理由：这个类只控制一个扫描环节。但这个环节和安全有关。确定性扫描器是安全防线的一部分。所以重要性略高于普通开关类。

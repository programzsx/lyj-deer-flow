# RunEventView档案

一、这个类是干什么的

RunEventView是持久化事件信封的数据类。seq在线程内单调递增。读取器返回的内容和元数据已从宿主存储脱离。字段是冻结的。嵌套的载荷容器可以在本地修改。这个类是frozen dataclass。

二、类的成员

（一）字段

- thread_id：字符串。默认值是空字符串。这个字段是线程ID。
- run_id：字符串。默认值是空字符串。这个字段是运行ID。
- seq：整数。默认值是0。这个字段是线程内的单调序号。
- event_type：字符串。默认值是空字符串。这个字段是事件类型。
- category：字符串。默认值是空字符串。这个字段是事件类别。
- content：Any。默认值是None。这个字段是事件内容。
- metadata：字典。默认值是空字典。这个字段是事件元数据。
- created_at：字符串。默认值是空字符串。这个字段是创建时间。

（二）方法

这个类没有自定义方法。这个类是纯数据类。

三、它和谁协作

RunEvidenceReader的list_run_events方法返回这个类。RunEventPage的items字段是这个类的元组。

四、重要性评级

评级：5分。

理由：这个类是运行事件的只读投影。扩展同步事件流靠它。所以重要性中等。

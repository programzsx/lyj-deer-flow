# MiddlewareDescriptor档案

一、这个类是干什么的

MiddlewareDescriptor是代理组装后单个中间件的描述数据类。描述记录名字、模块、策略参数和贡献者。这个类是frozen dataclass。

二、类的成员

（一）字段

- name：字符串。这个字段是中间件的类名。
- module：字符串。这个字段是中间件所在的模块。
- policy_parameters：字典。默认值是空字典。这个字段是中间件声明的行为参数。
- extension：字符串或None。默认值是None。这个字段是贡献这个中间件的扩展名。宿主中间件为None。扩展贡献的中间件在包装器里。包装器的类名被所有贡献者共享。没有这个字段两个扩展的中间件无法区分。

（二）方法

这个类没有自定义方法。这个类是纯数据类。

三、它和谁协作

AgentAssemblyDescriptor的middlewares字段是这个类的元组。指纹计算用这些字段。中间件不排序。栈顺序决定包装关系。

四、重要性评级

评级：5分。

理由：这个类是代理指纹的中间件部分。extension字段解决了包装器同名的问题。所以重要性中等。
